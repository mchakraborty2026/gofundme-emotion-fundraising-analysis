# Statistical Results

This folder contains the statistical tables generated
during the GoFundMe emotional tone analysis.

The analysis compares two emotion dictionaries:
GALC (Geneva Affect Label Coder) and EmoLex
(NRC Emotion Lexicon).

The results include descriptive statistics, regression
coefficients, robust standard errors, p-values,
and sensitivity analyses.

Two fundraising outcomes were examined:

1. Percentage of fundraising goal achieved.
2. Number of donors.

The analysis was conducted using Python and
statsmodels with HC3 robust standard errors.
